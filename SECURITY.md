# Security policy

## Supported versions

Only the latest release gets security fixes.

## Reporting a vulnerability

Please don't open a public issue. Report it privately through [GitHub private vulnerability reporting](https://github.com/vecvel/postcrate/security/advisories/new) or by email to support@vecvel.com.

Include the steps to reproduce, the affected version and platform, and what an attacker could do. We'll reply within a week and keep you updated until it's fixed.

Postcrate stores everything on the device and has no server, so most reports will concern local data, shared files or links handled by the app.
